## 3. Formal objects and designs (as stated in the sources)

**Bit accounting (bit-accounting, bit-accounting-arc).**
- Code at layer l: z = g(λ) ν(h_l) + ε, with ε ~ N(0, I). The encoder chooses ν and, through the gain g, each latent's SNR. "Fixed noise with a chosen power is the same channel as fixed power with a chosen noise" (Kelvin's point).
- Rate: E[log2 q(z|h) − log2 p(z)], with p a learned prior. This upper-bounds I(h_l; z).
- Distortion: decode to a layer-l state, run the real rest of the net: nMSE = E|â − a|² / tr Var a.
- R(ε) is the lower convex hull of (nMSE, rate) points (time-sharing). Slope = bits per halving of the output RMS error = 2 dR / d log2(1/ε). "for a Gaussian source at high resolution it is the number of directions being resolved."
- Classes: *local* (one ReLU layer of width n, then affine: "it can compute the next layer but not the rest of the net"); *unrestricted* (any MLP, which also sees the exact output, so "it can take the shortcut").
- PROVEN: every code of a layer is a code of the output, so every layer's count in any class is at least the output's rate-distortion function R_a(D). If the wanted reconstructions are reachable, unrestricted counts all equal R_a, and R_l ≤ R_{l'} for l < l'.
- Closed-form reference (HEURISTIC predictor): G = E[JᵀJ], J = da/dh_l, whitened, eigenvalues λ_i. Then R_wf(ε) = Σ_i max(0, ½ log2(λ_i/θ)) with Σ_i min(λ_i, θ) = εV. Learned local count / R_wf = 0.69-1.01 at 1% error over every measured ARC layer and net (0.51-0.83 at 10%).
- Phase-2 "unscrambling" price: (Lagrangian(μ) − Lagrangian(0))/λ when the next code is penalised toward an affine function of the current one.

**Backward bits (backward-bits; PROVEN in its FORMAL.md, audited by gpt-6-astra).**
- T_l = H(c_{l+1}) − E H(c_{l+1} | h_l) = I(h_l; c_{l+1}): "bits of layer l+1 minus the bits the noise erases". I*_l = I(h_l; c_L) is the truth.
- Prop 1: no function of h_l carries more than T_l about c_{l+1}, and T_l ≤ H(c_{l+1}).
- Prop 2: with Gaussian noise between layers, a non-constant partition code satisfies I(c_l; c_{l+1}) < H(c_l) strictly. "A code whose rate equals T_l carries strictly less than T_l."
- Prop 3: carrying all of T_l takes infinite rate. HEURISTIC: the shortfall falls like 2^(−2R/d).
- Prop 4: if c_{l+1} were sufficient for c_L, then T_l = I*_l + I(h_l; c_{l+1} | c_L) ≥ I*_l. With a lossy c_{l+1}, T_l can fall below I*_l. "T_l is a property of the chain's own codes, not of the net."
- Point 5 (CITED): with shared randomness, T_l bits per sample (reverse Shannon) or at most T_l + log2(T_l + 1) + 5 bits one-shot (Li and El Gamal 2018) let the receiver generate a next code with the right statistics. Reproducing the sample's own next code under shared future noise needs H(c_{l+1} | ξ_{l+1}) = T_l + I(h_l; ξ_{l+1} | c_{l+1}) ≥ T_l. "with shared noise, nothing is erased."
- Prop 7: if each layer's code is a re-simulation of the next, the targets telescope: T_l = I*_l at every layer, with no drift. "Deterministic partitions are never re-simulations."
- Four rule variants: K (rate ≤ target), R (carry ≥ 95% of the next code), P and PR (the same rules with the output code as the fixed target).

## 4. What was tested and what it showed (brief)

- **Estimability penalty (27 Oct).** Q: can a transformer be trained to be deductively estimable without losing the task? R: estimation error fell 9-191x for +0.003-0.004 nats (25-38% of the gap to Bayes). The penalty was met by Gaussianising the residual stream, not by predicting its non-Gaussianity. Every arm still loses to sampling at matched compute. Flaws: easy task, 3 seeds, a structured K = 4 that adds nothing over K = 2, a loose prereg tolerance.
- **Input bits (31 Oct).** Q: Kelvin's "some of the bits come from the input". R: input variance splits exactly into radius/amplitude/direction (ARC: 0.034/0.49/0.47). Input gate bits decay like 3n/l (kernel contraction, not Lyapunov). Low-order ANOVA shares are flat in width, and RQMC gains fall because the sampler cannot use pairs when N < d. Flaws: 2-4 nets per cell, heavy tails, finite-budget gains only.
- **Bits-bounds (1 Nov).** Q: a theory of the bits at layer l and of the hash argument. R: N_l(ε) ≈ (d_l/p) log2(D_l(1)/ε²) passed a registered test, but mostly by separating many-bit cuts from zero-bit cuts (5 of 13 intermediate counts within 2 bits). The lower-bound version holds only for an idealised source. Hash refuted in its exp(k*) form. Flaws: post hoc fits, k-means cells.
- **Relevance (1-2 Nov).** Q: count of output-relevant directions per layer. R: N(l, 0.01) = 256, 192, 128, 80, 48, 48, 48 at l = 0-31 of ARC (tested subspaces, not optima). Thousands of gates. The future cannot be seen from the past (Theorem 1). Flaws: Gaussian replacement of clouds; the mean-degree tests missed their joint criteria.
- **Bit accounting, small nets (1-2 Nov).** Q: certified bits-vs-accuracy curve per layer. R: unrestricted ≈ output count at every layer. Local counts rise steeply toward the input (32x32: 41 bits at l = 0 vs 1.9 at the output, 10% error). Code-to-code maps are near-affine on ReLU and on chaotic tanh alike, so the near-identity hypothesis does not discriminate. The S3 curriculum autoencoder alone is useless at the input, and far-horizon weighting fixes it from L/4. S4 shared-noise counts track memory. Flaws: early-layer counts not converged; one tanh seed; anchored codes started affine.
- **Bit accounting, ARC (2 Nov).** Q: the same at 256x32. R: 630 bits (10%) / 1139 (1%) at layer 0 against 19/89 at the output. The profile follows the future-weighted spectrum (reverse water-filling 0.69-1.01 at 1%). The backward curriculum lowers nothing. Flaws: 1% counts at layers 16-31 still falling 3-6% per doubling; random starts beat informed ones at low precision.
- **Backward bits (2 Nov).** Q: Kelvin's recursion. R: the target is certified (262/264 steps). Fixed codes keep 51-78% of T per step and the chain drifts to a median 26% of truth at the input. The "carry 95%" rule never compresses. Output-anchored PR keeps 74-91%. Re-simulation codes are exact (Prop 7). Flaws: one 64-cell output quantiser, small nets, noise tuned per config.
- **Future-aware (2 Nov).** Q: does a backward pass rescue layer-wise deduction? R: future directions beat PCA 2-3x at k = n/4, but the relevance participation ratio grows like n (17.5, 33, 67, 127.5 at n = 64-512). Best window is about 1.3-2.4x over RQMC under hypothetical costs, not growing. Flaws: hypothetical cost models, numerically indefinite ARC states.

## 7. Tensions

1. **Information vs computation.** His founding question (2.5) asked for an information-theoretic account of "bits that matter". The lanes proved that information is layer-free in noiseless nets. Only computationally restricted classes see layer-dependent bits. He acknowledged this (2.15) yet kept using "bits" until 2 Nov (2.25). The theme never settled which restricted class defines "the bits that matter" (local one-ReLU encoders? forward-only cells? linear point rules?). Each lane picked a different one.
2. **"The final part is hard to average" vs "the final layers are the easiest".** His 31 Oct and 3 Nov form of the hash conjecture puts the hardness in averaging a decode over a pseudorandom code. Bits-bounds F2 measured the opposite: the variance is made in the first few dozen layers (share left after l ≈ 8.3/(l + 9)), and the final layers need the fewest bits. His conjecture can be repaired by putting the "decode" early, but it was never restated that way.
3. **Bits do not price estimation.** Averaging over a code with the right decoder is unbiased at any rate. So the whole accounting, however certified, could not by itself yield either the positive or the negative he demanded. This explains his verdict.
4. **Deduction-only vs sampling.** He wanted a purely deductive estimator, accepted "the sampling direction" for two hours, then dismissed it. His 2 Nov expert design reintroduces targeted sampling for the uncertain parts. In the current agenda this tension reappears as search (sampling-like) vs a distilled network (deductive).
5. **Layer factoring vs skipping.** "I am not happy with any idea that doesn't use the 'natural factoring' of the layers" vs "I dont want to get constrained by only layer-by-layer structures". Future-aware's unconditional statement shows why this matters: any algorithm is a fully future-aware layer-wise estimator, so "layer-wise" only bites when the interface is restricted.
6. **Estimability vs task.** The penalty "succeeded" but did so by Gaussianising, which he rejected. That matches his current refusal to train the base model M for consistency (it degrades stiff predictions). The estimability result is a small piece of evidence for that refusal: forcing a deductive summary to match costs real task loss.
7. **Bootstrapped targets drift; anchored targets do not.** His backward recursion (rate = target computed from the chain's own next code) drifted to 26%. Output-anchored targets kept 74-91%, and stochastic re-simulation was exact. This is in tension with any amplify/distill loop whose target is computed through the previous distillate, which is ingredient (6) of the current agenda (9.3).
8. **Explicit vs implicit.** The ARC thread tried to understand an implicit dense computation. The current agenda gives that up for an explicit one. The bits results are, in effect, the evidence for the pivot, but he never stated the link. His 29 Oct request (2.10), "evidence... that we really wont be able to interpret... wide deep fully-connected networks" before building interpretable architectures, was never satisfied with a proof. Only empirical and restricted-class negatives exist.

## 9. Leverage points

**9.1 The bit-accounting split is a ready-made test of hypothesis (6).**
- Established (PROVEN in the lane): every code of a layer is a code of the output, so R_l(D) ≥ R_a(D) in any class. Unrestricted codes reach R_a (measured on 105/114 points). Local codes need far more toward the input (ARC: 630 vs 19 bits at 10%; 32x32: 41 vs 1.9).
- Established (MEASURED, HEURISTIC as a predictor): reverse water-filling on the whitened future-weighted Gram E[JᵀJ] predicts the local count within 0.69-1.01 at 1% error, with no training.
- Conjecture: map "target" to T or the goal variable, "layer" to the world model's latent s, and "local class" to the capacity of the distilled policy or goal network. Then R_T(D) measures the size of W, and R_local(l, D) − R_T(D) measures what the search/heuristic must supply.

Kelvin's crucial hypothesis ("W needs far fewer parameters than the search-policy network") becomes R_T ≪ R_local. That is measurable on a trained world model with the existing pipeline, or cheaply with the water-filling closed form: the participation ratio and spectrum of E[JᵀJ] of the goal with respect to s. The bits work "taught nothing" for ARC because bits do not price estimation. But it is exactly the right instrument for the separation the current agenda needs. FROM MEMORY, unverified: this layer-dependence of information under computational restriction is what "usable" or V-information formalises (Xu, Zhao, Song, Stewart, Ermon, ICLR 2020). V-information can increase under computation, unlike Shannon information. That literature may supply definitions and estimation bounds.

**9.2 Policy independence as martingale convergence; the uncertain-model case.**
- Established (standard probability, FROM MEMORY, unverified in this corpus): if amplified beliefs are B_c = E[X | F_c] for a filtration F_c generated by the computations performed, they form a martingale. B_c converges to E[X | F_∞] (Lévy's upward theorem). Two search policies are two filtrations. Their limits coincide iff their terminal σ-algebras agree, i.e. every policy eventually performs every relevant computation (the analogue of UCT's infinitely-many-visits condition).
- In the corpus, bits-bounds proved that one martingale (the log-radius difference) has its quadratic variation concentrated early. The relevance value function g_l(h_l) = E[a | h_l] is the Doob martingale of the net. In noiseless nets it is constant in variance across l, so information is "layer-free".
- Conjecture: for Kelvin's inconsistent M there is no single X. The open "what is T for an uncertain model" is then "what replaces E[X | F_∞]". If T is defined as the minimiser of an inconsistency (PDG/LIR), policy independence requires that minimiser to be unique and reached by every admissible resolution order. FROM MEMORY, unverified: Richardson and Halpern's PDG semantics give a unique distribution when the scoring function is strictly convex (small γ), and LIR's fixed points need not be unique in general. If so, (3) reduces to a convexity or uniqueness condition on the inconsistency, a checkable mathematical target.
- Caution, FROM MEMORY, unverified: logical inductors' limits are coherent but depend on the construction. "Approximate martingale over computation" à la logical induction does not by itself give policy independence.

**9.3 Bootstrapped amplification drifts; anchored or re-simulated targets do not.**
- Established (PROVEN in backward-bits): Props 2, 4 and 7. Partition codes cannot carry their own rate. A target computed through the chain's own lossy codes is "a property of the chain's own codes, not of the net" and can fall below the truth. Re-simulation (stochastic) codes make the targets telescope exactly.
- Measured: Kelvin's rule ends at about 26% of the truth. Output-anchored PR keeps 74-91%, at about 2x the surviving information in rate.
- Conjecture: an amplify/distill loop whose amplification target is computed from the previous distillate is the K chain. It drifts unless the target is anchored to something outside the chain (AlphaZero's game outcome is the PR anchor) or is a stochastic re-simulation through M (rollouts/sampling, Prop 7's case). Prediction for ingredient (6): distillation fidelity per round must be very high (99% per step kept 98% in the exact 1-D chain; 95% kept 74%), or T must be anchored.

Kelvin needs to say what plays the role of the "game outcome" for an uncertain world model (question 10.4).

**9.4 Beliefs vs plans: sum vs max.**
- Established (corpus, mostly restricted classes): for expectations under random-like structure, every deductive scheme tested gave constant factors over RQMC. Regions chosen without the weights gain at most about 2x (reported). Prop 9.1 shows the gain from structure-free knowledge is at most about 4x at intermediate budgets. C4 conjectures nothing beats the best multilevel sampler polynomially at depth proportional to width. The assistant's "A sum, not a max" (2.26) states the reason: in an integral every region counts by its mass, so only variance or certificates let you skip one.
- Conjecture: his open question "can beliefs and plans be searched in almost the same way" has a principled no for generic structure. The max part of T (planning) admits pruning, so a good heuristic changes asymptotic cost. The expectation part (belief over hidden s) admits only (a) certified regions where the integrand is known (his f = c regions, the analogue of α-β bounds), (b) stratification, or (c) real structure in M. Otherwise the heuristic buys constants and the cost rate stays at the sampling rate.

Two consequences for the agenda. First, Go is deterministic, which is why the MCTS model is so clean. With an uncertain M, chance nodes reintroduce the integral, and "alien concepts" can only speed up the max part unless M is structured. Second, "stiff" predictions are the belief-side analogue of certified regions: they can be skipped. Non-stiff ones must be sampled or searched.

**9.5 His exact-mean experts with confidence are Bayesian quadrature (probabilistic numerics).**
- FROM MEMORY, unverified: functions in the span of Gaussian RBF kernels have closed-form expectations under Gaussian inputs. That span is dense in continuous functions on compacta, which answers "fully expressible in the limit" (question 6.3). Bayesian quadrature puts a GP prior on the integrand and returns a posterior mean and variance for the integral. That gives exact means, a calibrated "I don't know", and uncertainty-targeted sampling, exactly his 2 Nov desiderata. Under the GP model, the BQ posterior mean of the integral is a martingale in the number of evaluations, the "approximately a martingale over further computation" property.
- Established in corpus: bits-bounds Thm 7.5 is the kernel-quadrature discrepancy for this class. Its conjectured rate M^{−1−3/d} (d ≈ n/l) explains why the experts lost on ReLU nets: kernel quadrature is cursed by the cloud's dimension at kinks.
- Conjecture: probabilistic numerics ("computation as inference") is the existing framework for (2) and (6) of the current agenda. It covers amplified beliefs about quantities defined by a model, updated by chosen computations, with policy-independent limits and the design affecting only speed. FROM MEMORY, unverified: for a GP with fixed hyperparameters, the optimal design does not depend on observed values, so adaptivity buys nothing. That is the same phenomenon as "regions chosen without the weights gain ≤ 2x", and it would be worth checking.

**9.6 Relevance Theorem 1: goal-relevance cannot be computed forward.**
- Established (PROVEN [C+A]): given the past, the next layer's transverse block is a fresh Gaussian. Every past-measurable angular direction has the same expected backward amplification. "only a backward pass can find" the relevant directions. Measured: in random nets the backward relevance spreads over Θ(n) directions (PR 17.5 to 127.5 at n = 64-512, proven in a mean-field model).
- Conjecture: in the agenda, which features of s matter is set by the goal, a future-side object. A world model trained without the goal cannot know it. This supports putting preferences in a separate small W read through backward sensitivities (the E[JᵀJ] pullback), and evaluating hypothesis (6) by the participation ratio of that pullback. If trained world models look like random nets here (PR ∝ width), (6) fails. If the PR is small, (6) holds. This is one cheap measurement.
