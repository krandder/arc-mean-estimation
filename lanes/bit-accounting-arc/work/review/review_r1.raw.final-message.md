**Verdict: fixable issues. The current scorer cannot support “as good as reasonably possible.”** Several problems can make reported bits optimistic or certificates falsely reassuring.

Checked against the latest registered hashes on 2026-11-02; existing files match. Verification used source, synthetic reproductions, and dev data only. No files changed; CUDA execution was not tested because PyTorch is unavailable.

1. **Major — incorrect covariance in the analytic anchor.** [vrlib.py:360](/home/agent/workspaces/mats/work/bit-accounting-arc/gpu_src/lib/vrlib.py:360), [ref_curve.py:90](/home/agent/workspaces/mats/work/bit-accounting-arc/gpu_src/scripts/ref_curve.py:90). Whitening gives covariance \(P_{\mathrm{keep}}\), but the Jacobian uses full-rank decoder frame `T`, including artificial null-space directions. Its eigen-coordinates therefore need not have unit variance, invalidating the claimed water-filling/LMMSE construction. A NumPy reproduction on dev ND111, layer 64, gives rank one but leading-coordinate variance **0.0049**. **Fix:** restrict the anchor spectrum to the retained data subspace; keep full-rank `T` for the learned decoder.

2. **Major — reported rates are estimates, not guaranteed upper bounds.** [vrlib.py:795](/home/agent/workspaces/mats/work/bit-accounting-arc/gpu_src/lib/vrlib.py:795), [score_P1.py:25](/home/agent/workspaces/mats/work/bit-accounting-arc/scratch/score_P1.py:25). Cross-fitting is valid, but selecting the minimum of four noisy held-out estimates introduces downward selection bias. Even an exact zero-information Gaussian channel can produce a negative empirical estimate when using analytic \(E\log q\). Refitted-rate uncertainty is not recorded. **Fix:** select priors on validation data, evaluate on an independent outer test set, and report uncertainty; qualify “upper bound” as a population statement.

3. **Major — refined distortion is extrapolated, then selected on evaluation data.** [score_P1.py:27](/home/agent/workspaces/mats/work/bit-accounting-arc/scratch/score_P1.py:27). The scorer reports `full_plain × subset_refined / subset_plain`, rather than either measured distortion. This ratio has no guaranteed direction of error; taking its minimum with plain distortion adds selection optimism. **Fix:** choose the decoder using validation data and measure it on a common outer test set. Refinement itself correctly targets the code-derived head, not the true output.

4. **Major — interpolated points are not certified achievable.** [vra.py:32](/home/agent/workspaces/mats/work/bit-accounting-arc/lib/vra.py:32). Synthetic endpoints `(R,D)=(0,1),(10,.01)` produce **5 bits at D=.1**; even linear time-sharing only guarantees 9.09 bits. **Fix:** use evaluated endpoints for upper-bound claims, or evaluate additional lambdas at queried accuracies. Label interpolation as descriptive.
